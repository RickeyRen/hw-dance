🚀 快速开始 · Getting Started

📱 首次使用 · First Launch

HW Dance 没有预设任何电脑地址，首次启动时需要选择你的 Windows 电脑：
HW Dance has no preset computer address, so on first launch you choose your Windows PC:

  1. Windows 端 / On Windows：启动 HWiNFO64 并启用 Server Role / TCP Server（默认端口 27007）。ASUS GPU Tweak HTTP（端口 5001）为可选辅助数据源。
    Start HWiNFO64 and enable Server Role / TCP Server (port 27007 by default). ASUS GPU Tweak HTTP (port 5001) is an optional extra source.
  2. 同一网络 / Same network：确保 Apple 设备与 Windows 电脑在同一局域网。
    Make sure your Apple device and the Windows PC are on the same local network.
  3. 选择电脑 / Choose the PC：在引导页或「设置 > 数据源」中扫描局域网，或手动输入 Windows 电脑的 IP 地址。
    Scan your network in onboarding or Settings > Data Sources, or enter the Windows PC's IP address manually.
  4. 演示模式 / Demo mode：没有 Windows 电脑时，也可以先用演示数据体验全部功能。
    No Windows PC handy? Try every feature with demo data first.

❓ 常见问题 · FAQ

Q: 显示「尚未设置 Windows 电脑」怎么办？ · What does "No Windows PC is set up yet" mean?
A: 应用还没有选定要监控的电脑。打开「设置 > 数据源」，扫描局域网或输入 Windows 电脑的地址后点击应用。
The app has not been pointed at a computer yet. Open Settings > Data Sources, scan your network or enter the Windows PC's address, then apply.
Q: 无法连接到 Windows 电脑怎么办？ · The app can't connect to my Windows PC.
A: 请检查 / Please check:
• HWiNFO64 正在运行，并已启用 Server Role / HWiNFO64 is running with Server Role enabled
• Windows 防火墙允许 TCP 27007（以及可选的 5001）/ Windows Firewall allows TCP 27007 (and optionally 5001)
• 两台设备在同一局域网 / Both devices are on the same local network
• 已在系统设置中允许 HW Dance 访问本地网络 / HW Dance is allowed Local Network access in System Settings
• 可在「设置 > 数据源」运行连接诊断 / Run the connection diagnostics in Settings > Data Sources
Q: HWiNFO64 免费版连接一段时间后断开？ · HWiNFO64 (non-Pro) disconnects after a while?
A: HWiNFO64 非 Pro 版的远程监控大约 12 小时后需要重新启用。断开期间 HW Dance 会使用最近一次真实快照回放，并明确标注为回放数据。
HWiNFO64 non-Pro remote monitoring needs re-enabling after about 12 hours. While disconnected, HW Dance replays the latest real snapshot and clearly labels it as replay.
Q: 支持哪些设备？ · Which devices are supported?
A: iPhone、iPad（iOS / iPadOS 26 及以上）和 Mac（macOS 26 及以上）。Windows 端需要 HWiNFO64；ASUS GPU Tweak 为可选。
iPhone and iPad on iOS / iPadOS 26 or later, and Mac on macOS 26 or later. The Windows PC needs HWiNFO64; ASUS GPU Tweak is optional.
Q: 数据隐私如何保障？ · How is my data protected?
A: 所有传感器数据只在你的设备上处理和保存，应用只连接你选择的 Windows 电脑。详见 隐私政策。
All sensor data is processed and stored on your device, and the app connects only to the Windows PC you choose. See the Privacy Policy.
