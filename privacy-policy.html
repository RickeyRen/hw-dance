HW Dance 隐私政策 · Privacy Policy

最后更新 / Last updated: 2026-10-20

📱 关于 HW Dance · About HW Dance

HW Dance 是一款运行在 iPhone、iPad 和 Mac 上的整机硬件监控应用，通过局域网读取你自己的 Windows 电脑上 HWiNFO64（主数据源）以及可选的 ASUS GPU Tweak HTTP 接口提供的传感器数据。

HW Dance is a whole-system hardware monitor for iPhone, iPad, and Mac. It reads sensor data over your local network from HWiNFO64 (primary source) and, optionally, the ASUS GPU Tweak HTTP interface running on your own Windows PC.

🔒 隐私承诺 · Our Commitment

HW Dance 不收集、不存储、不向我们传输任何个人数据。

HW Dance does not collect personal data, and nothing is sent to us.

📊 数据处理说明 · How Data Is Handled

  • 硬件传感器数据 / Sensor data：只在你的设备上处理和保存（包括最近快照和本地历史记录），不会上传到任何服务器。
    Processed and stored only on your device (including the latest snapshot and local history). It is never uploaded to any server.
  • 应用设置 / Settings：包括你选择的 Windows 电脑地址，只保存在本机。
    Including the Windows PC address you choose, stored only on this device.
  • 演示数据 / Demo data：演示模式使用本地生成的模拟数据。
    Demo mode uses simulated data generated on the device.
  • 购买 / Purchases：订阅或买断由 Apple 通过 App Store 处理，我们收不到你的付款信息，应用只读取购买状态。
    Subscriptions and lifetime purchases are processed by Apple through the App Store. We never receive your payment details; the app only reads your purchase status.

🌐 网络连接 · Network Connections

  • 没有预设电脑 / No preset computer：应用没有内置任何主机地址。首次启动时，由你在局域网中扫描或手动输入要连接的 Windows 电脑。
    The app ships with no host address. On first launch, you scan your local network or enter the Windows PC you want to connect to.
  • 仅限本地网络 / Local network only：只连接你选择的 Windows 电脑；局域网发现只在本地网段内校验 HWiNFO64 传感器报告。
    The app connects only to the Windows PC you choose. LAN discovery checks for HWiNFO64 sensor reports only on your local subnet.
  • 无外部通信 / No outside connections：不连接任何第三方服务器、分析或广告服务。
    The app connects to no third-party servers, analytics, or advertising services.

🛡️ 权限使用说明 · Permissions

  • 本地网络 / Local Network：用于连接你配置的 Windows 电脑并读取 HWiNFO64 与可选 GPU Tweak HTTP 数据，数据不会离开你的局域网。
    Used to connect to your configured Windows PC and read HWiNFO64 and optional GPU Tweak HTTP data. The data never leaves your local network.
  • 相机 / Camera：仅在你主动选择扫描 ASUS GPU Tweak 连接二维码时使用，图像不会被保存或上传。
    Used only when you choose to scan an ASUS GPU Tweak connection QR code. Images are never saved or uploaded.
  • 通知 / Notifications（可选 / optional）：仅用于提醒 HWiNFO64 会话即将或已经断开。
    Used only to alert you when an HWiNFO64 session is about to disconnect or has disconnected.

🔐 数据安全 · Security

  • 不使用第三方分析、广告或跟踪 SDK。
    No third-party analytics, advertising, or tracking SDKs are used.
  • 不收集设备标识符或使用统计。
    No device identifiers or usage statistics are collected.

💳 应用内购买 · In-App Purchases

HW Dance Pro 的订阅和买断购买完全由 Apple App Store 处理。我们不会收到或保存你的付款信息、Apple ID 或个人身份信息；应用只在本机读取 Apple 提供的购买状态以解锁功能。

HW Dance Pro subscriptions and lifetime purchases are processed entirely by the Apple App Store. We never receive or store your payment details, Apple ID, or personal identity; the app only reads the purchase status Apple provides on your device to unlock features.

🔄 政策更新 · Changes

如果隐私政策有重大变化，我们会更新本页的“最后更新”日期，并在应用更新说明中告知。

If this policy changes materially, we will update the "Last updated" date on this page and mention it in the app's release notes.
